# 中文论文模式

处理中文毕业论文模板、封面、前置页、目录或分节时阅读本页。学校的正式模板和论文规范优先。

模板出现“摘要 + 关键词 + 参考文献”等高置信信号时，系统选择 `thesis` Profile。它可以：

- 区分摘要标题/正文、关键词、章标题、参考文献标题/条目、公式、附录和图表目录标题；
- 只给“摘要：”“关键词：”标签加粗，参考文献条目使用悬挂缩进；
- 从模板提取校名、论文类型和校徽，并从源稿显式标签回填作者、导师、学院等封面字段；未知字段显示“（待填写）”；
- 重建封面、摘要、目录、正文和参考文献分节；前置页使用罗马页码，正文从阿拉伯数字 1 开始；
- 用真实 TOC、STYLEREF 和 PAGE 域生成目录、动态章页眉和页码。

系统不会复制模板中的示例作者、英文题名或法律声明；声明页默认关闭。

## 清洗策略

- `controlled`：只清理规则明确控制的直接格式。
- `strict`：用于强模板迁移，清理异常斜体、下划线、颜色、高亮、删除线和字符样式。
- `preserve_emphasis`：清理主要噪声，但保留作者有语义的粗斜体、小型大写、语言和 RTL 属性。

论文模板通常选择 `strict`；混有公式变量、外文题名或强调格式时，先评估是否应改用 `preserve_emphasis`。

```bash
python main.py --template thesis-template.docx \
  --target thesis-source.docx --out output/thesis.docx \
  --cleanup-mode strict --refresh-fields
```

## 结构风险

- 源稿已有横向宽表、不同栏数、独立页眉页脚、附录页码或复杂分节时，结构重建默认阻断。
- `--allow-risky-structure` 只在用户已备份并明确理解分节会被重构时使用。
- 自动题注只接受单段简单整数编号。公式编号、章节式图号、跨 Run 题注和交叉引用不得猜测转换。
- 复杂封面、声明、英文扉页和专用书脊仍应使用学校模板并人工复核。
